# Xuất Chứng Từ Kế Toán
Chương trình xuất chứng từ kế toán Excel theo mẫu Phụ lục 1 Thông tư số 99/2025/TT-BTC

## Tính năng chính
- **Xuất báo cáo:** Xuất báo cáo chứng từ ra định dạng `.xlsx` theo mẫu từ dữ liệu đầu vào

## Công nghệ & Thư viện sử dụng
- **Language:** C# (.NET Framework 4.8)
- **Application Type:** Console Application
- **Libraries:** Aspose.Cells - Xử lý template và xuất file Excel

## Hướng dẫn cài đặt và chạy dự án
### 1. Yêu cầu hệ thống
- **Hệ điều hành:** Windows (vì .NET Framework 4.8 chạy tối ưu trên Windows)
- **Công cụ phát triển:** [Visual Studio](https://visualstudio.microsoft.com/)
- Đảm bảo đã cài đặt **.NET Framework 4.8 Developer Pack** trong Visual Studio Installer

### 2. Cài đặt dự án
1. **Clone repository về máy:**
  ```bash
  git clone https://github.com/truongcongvien/XuatChungTuKeToan.git
  ```

2. **Mở dự án:**
- Mở file giải pháp `.sln` hoặc `.slnx` (Solution file) của dự án bằng phần mềm **Visual Studio**

3. **Khôi phục các NuGet Packages:**
- Nhấp chuột phải vào tên Solution trong cửa sổ **Solution Explorer** -> Chọn **Restore NuGet Packages**
- Hoặc khi chạy, Visual Studio sẽ tự động tải về

4. **Build (Biên dịch) dự án:**
- Trên thanh menu, chọn `Build` -> `Build Solution`

5. **Chạy ứng dụng:**
- Nhấn nút **Start** màu xanh lá trên thanh công cụ của Visual Studio để chạy ứng dụng Console
